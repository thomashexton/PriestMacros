# PriestMacros

WoW Forever addon that installs mouseover-aware priest character macros.

## Usage

In game, run:

```
/priestmacros
```

That command replaces this character's priest macros. It does not run on login by itself. The character must be a priest and out of combat.

## Forever

Built for **WoW Forever** (`Interface: 16001`). Drop the `PriestMacros` folder into `_forever_/Interface/AddOns/`.
